Robot

class pyniryo.nate.components.Robot(http_client: HttpClient, mqtt_client: MqttClient, correlation_id: str)[source]

Bases: BaseAPIComponent

Robot component for controlling robot movements and accessing robot state.

This component provides methods for: - Getting and monitoring joint positions - Moving the robot using joints, poses, waypoints, or trajectories - Managing frames and coordinate systems - Controlling robot execution (pause, resume, stop) - Jogging in manual mode

Moving the arm is direct control, which the robot accepts only when its key selector is on manual, with one exception for the program it is running. See Direct control.

  • linear (bool) – If True, use linear interpolation (Planner.LIN) for a straight-line path. If False (default), use point-to-point planning (Planner.PTP).

jog_mode() → Generator[None, Any, None][source]

Context manager to temporarily set the robot in jog mode. The robot will be set back to its previous control mode when exiting the context.

This context manager only sets the control mode, so it is not the guard it looks like. From an outside script it raises on automatic, on entry, and a key turned to automatic during the block makes the exit raise too, leaving the robot in jog mode. From a program it opens without a word, and the jog commands inside the block are then dropped in silence. See Direct control.

Usage: ``` with robot.jog_mode():

# Do something in jog mode …

# Back to previous control mode ```

Raises:

ClientError – If the robot refuses to set the mode because its key selector is on automatic.

Return type:

Generator[None, Any, None]

The robot decelerates to a stop when the command is not renewed within 50 ms, or on stop_jog(). See jog_joints_increment() for a one-shot move by an increment.

jog_joints_increment(increment: Joints) → None[source]

Move each joint once by the given increment. The robot must be in jog mode for this to work.

The motion runs to completion, stop_jog() does not interrupt it. An increment whose end lands past the travel the jog controller allows is refused whole and nothing moves; the controller keeps a margin on each side of a joint limit and reports that travel, see on_jog_limit_violation(). A single command carrying both an increment and velocities moves by the increment. See jog_joints() for a continuous move at a given velocity.

Direct control: the key selector must be on manual, with no exception for a running program. On automatic the robot drops the command and answers nothing, see Direct control.

Parameters:

increment (Joints) – The joint increments of the jog command (in rad), counted from the current joint positions.

Return type:

None

set_target_speed(factor: float) → float[source]

Set the target speed factor of the robot. :param factor: A factor comprised between 0 and 1. A factor of 1 means the robot will move at its maximum speed, while a factor of 0.5 means the robot will move at half of its maximum speed. Setting the speed factor does not change the underlying trajectories, it only scales the speed at which they are executed. :return: The target speed factor the robot applied. :raises ClientError: If another workstation holds the robot (code == 'robot_held').
